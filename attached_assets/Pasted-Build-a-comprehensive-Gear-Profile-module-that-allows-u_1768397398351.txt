Build a comprehensive "Gear Profile" module that allows users to create, save, and edit highly specific equipment configurations for different diving environments. These configurations must act as Templates that can be applied to a dive log and modified without altering the master template.

1. Core Data Architecture
The system should be categorized into four primary modules:

A. Configuration Type (Conditional UI)
Use a visual, icon-based selector. The choice here must dynamically update the Gases and Weighting sections:

Single Tank: Standard recreational setup.

Twinset: Double back-mount cylinders with manifold.

Sidemount: Dual side-mounted cylinders.

CCR (Closed Circuit Rebreather): On-board Diluent/O2 + Bailout options.

B. Exposure & Environmental Gear
Provide a nested selection for thermal protection:

Suit Type: Dropdown (Drysuit, Wetsuit, Rash Suit).

If Wetsuit selected: Sub-options for thickness (2mm, 3mm, 5mm, 7mm, 10mm).

If Drysuit selected: Add "Undersuit" field with text input (e.g., "Fourth Element Halo").

Accessories: * Gloves: (Dry, Wet: 2mm to 9mm).

Boots: (Dry, Neoprene: 2mm to 9mm).

Customization: Every item must have an optional Nickname field (e.g., "My O3 Trilaminate").

C. Dynamic Weighting System
Weight placement should change based on the Configuration Type:

CCR: Fields for "On-board Cylinders (Top)", "Harness", and "Weight Belt".

Twinset: Fields for "V-Weight" (between cylinders), "Tail Weight", "P-Weight", and "Belt".

Sidemount: Specific fields for "Spine" (Top, Middle, Bottom positions) and "Harness/Belt".

D. Gas & Cylinder Management
Provide a database of standard cylinder sizes (3L, 5L, 7L, 10L, 12L, 15L, AL80) and materials (Steel/Aluminum).

Role Assignment: Each cylinder needs a "Use" label: Bottom Gas, Travel Gas, Deco Gas, or Diluent/O2 (for CCR).

Smart Defaults: * Single Tank = 1 slot.

Twinset/Sidemount = 2 primary slots + optional stages.

2. Template & Planning Logic
Save as Template: Users can save a configuration as "UK Cold Water Drysuit" or "Red Sea Sidemount."

Apply to Dive: When a template is added to a dive log, it creates a Local Instance. Changing the weight or gas on a specific dive must NOT change the original template.

Planning Fields: Include global inputs for Planned Depth (m) and Bottom Time (min) to assist with gas requirements.

3. UI/UX Requirements
Iconography: Use clear diving-specific icons for tank configurations and suit types.

Input Handling: Use "steppers" (+/- buttons) for weights and cylinder volumes for easy use with wet hands or on mobile.
