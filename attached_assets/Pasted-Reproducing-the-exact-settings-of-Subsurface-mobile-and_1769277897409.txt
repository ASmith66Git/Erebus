Reproducing the exact settings of Subsurface-mobile and libdivecomputer is theoretically possible because both are open-source and follow a strict, reverse-engineered protocol for Shearwater devices.Below is the technical breakdown of the 0x8020 (Log Manifest) response and the stability settings used by libdivecomputer to ensure the Erebus app mirrors the industry standard.1. The 0x8020 Response Structure (Log Manifest)When you send the 0x22 0x80 0x20 request, the Perdix returns a 9-byte payload encapsulated in the UDS response frame (01 FF [Len] 00 62 80 20 ...).Byte IndexField NameDescription0SID ACK0x62 (Positive response to 0x22).1-2DID0x80 0x20 (Confirms the identifier being read).3-4Dive Count16-bit Big Endian integer representing total dives on device.5-6Latest DiveID of the most recent dive recorded.7-8Oldest DiveID of the oldest dive still in memory.2. Exact Settings from Subsurface-mobileTo replicate Subsurface's reliability, your Erebus app must adopt these specific "hidden" settings found in their GitHub repositories:Handshake Timing: Subsurface implements a "stabilization window" where it waits up to 3000ms after service discovery before sending the initial 0x35 handshake.The "Wait for BLE" Sequence: A known reliability fix in the community is to put the app into "Download" mode before starting Bluetooth on the Perdix. This ensures the phone is already scanning the moment the Perdix starts advertising.Auto-Connect vs. Manual: Subsurface-mobile utilizes a manual connection drop-down to force the user to select the specific hardware ID (e.g., Perdix xx:xx:xx), which helps bypass iOS's tendency to cache stale device names.Legacy UI Toggle: For older firmware or persistent errors (like "Send Packet Err"), Subsurface and Shearwater Cloud both offer a Legacy UI or Legacy Bluetooth mode that uses a simplified protocol.3. Native BLE RequirementsSince you are using Replit and Expo, the Erebus app will only function if you build it as a Native Development Build.No Expo Go: You cannot use the standard Expo Go app to test this; it lacks the native react-native-ble-plx libraries required for these protocols.iOS Support: On iOS, only Bluetooth LE (BLE) is supported for dive computer downloads.Troubleshooting "The Hardest Connection"Community developers for Subsurface note that the initial connection is often the hardest. If the 0x35 or 0x8020 requests continue to time out, the standard "Nuclear Option" is to:Forget the computer in all other apps and OS settings.Restart the mobile device to clear the system's CBCentralManager cache.Cycle the Perdix battery (remove for 60 seconds) to reset its internal radio.
